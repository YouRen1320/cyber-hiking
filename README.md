# 赛博徒步

一个以鳌太线户外风险为背景的微信小程序文字剧情游戏。玩家通过角色选择、资源管理和分支事件体验不同结局；内容用于情景体验与户外安全科普，不是路线攻略，也不构成前往危险区域的建议。

## 当前状态

- 当前版本：1.0.2，详见 [`doc/版本说明.md`](./doc/版本说明.md)。
- 已包含角色选择、随机事件、天气、物品、图鉴、日志、存档和背景音乐。
- 游戏进度保存在微信本地存储中，没有服务端账户或云端同步。
- 本仓库是当前维护版本；早期 UniApp 实现在 [`Braving_Aotai_Trail`](https://github.com/YouRen1320/Braving_Aotai_Trail)，手工资源分包版本在 [`Braving_Aotaixrail_weixin`](https://github.com/YouRen1320/Braving_Aotaixrail_weixin)，两者均已归档。

## 本地运行

1. 安装微信开发者工具。
2. 导入仓库根目录。
3. 没有当前 AppID 权限时，在开发者工具中改用自己的测试号或 AppID。
4. 编译后从首页进入游戏，重点检查存档、角色解锁、音乐开关和不同结局。

项目不依赖 npm，也没有单独的构建脚本。

## 数据与隐私边界

- `braving_aotai_save_v1` 和 `braving_aotai_meta_v1` 保存于用户设备的微信本地存储。
- 启动代码会调用 `wx.login`，但当前实现不读取、上传或使用返回的登录凭据。
- 当前代码没有业务后端或网络请求；背景音乐来自仓库内的本地资源。
- 清除小程序数据会同时清除本地进度，当前不提供跨设备恢复。

## 项目结构

```text
lib/core/       游戏流程、元数据与存档
lib/model/      角色、物品、天气、场景与结局
lib/store/      状态存储
lib/utils/      音频和背景资源工具
pages/          首页、角色、游戏、图鉴与日志页面
assets/audio/   本地背景音乐
doc/            版本说明
```

## 重要说明

鳌太线自然条件复杂且风险极高。游戏中的数值、情节和选择经过抽象，不应作为真实户外决策依据。真实活动请遵守当地管理规定，并以官方风险提示和专业救援建议为准。
